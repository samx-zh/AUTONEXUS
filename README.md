## AUTONEXUS
AUTONEXUS is a front-end web application designed for car enthusiasts and buyers who want a modern, immersive platform to explore vehicle suggestions and data analysis. The platform greets users through a styled authentication portal and delivers a rich dashboard experience for navigating automotive content.
Whether you're looking for performance specs, feature comparisons, or personalized car suggestions — AutoNexus puts it all in one sleek interface.

## THEME
Color Palette: Deep charcoal backgrounds with golden amber (#E8B400) accents, creating a premium, high-contrast feel.|
Typography: Orbitron (display/brand) paired with Exo 2 (body) — both designed for a tech-forward, motorsport-inspired look.
Motion: Animated road lines on the login screen, smooth transitions, and hover micro-interactions throughout.
UI Language: Card-based layouts, glowing borders, gradient accents, and a bold brand presence — built for an immersive user experience.

## FEATURES
🔐 Authentication Portal — Secure login system with form validation, session management via sessionStorage, and toast notifications
🏠 Home Dashboard — Central hub for navigating car content after authentication
🚘 Car Suggestions — Curated vehicle recommendations based on user preferences
📊 Analysis View — Data-driven insights and comparisons between vehicles
📱 Responsive Design — Optimized for both desktop and mobile viewports
🎞️ Animated UI — Smooth CSS animations including road-line motion effects on the login page
🛡️ Auth Guard — Pages redirect unauthenticated users to the login screen automatically

## TECHNOLOGIES USED
HTML5Page - structure and semantic markup
CSS3 - Styling, CSS variables, animations, responsive layout
JavaScript (ES6+) - Interactivity, DOM manipulation, session management
Google Fonts - Orbitron & Exo 2 typefaces
sessionStorage API - Client-side authentication state
Node.js / npm - Development tooling and package management
