## AUTONEXUS
AUTONEXUS is a front-end web application designed for car enthusiasts and buyers who want a modern, immersive platform to explore vehicle suggestions and data analysis. The platform greets users through a styled authentication portal and delivers a rich dashboard experience for navigating automotive content.
Whether you're looking for performance specs, feature comparisons, or personalized car suggestions — AutoNexus puts it all in one sleek interface.

## THEME
Color Palette: Deep charcoal backgrounds with golden amber (#E8B400) accents, creating a premium, high-contrast feel.
Typography: Orbitron (display/brand) paired with Exo 2 (body) — both designed for a tech-forward, motorsport-inspired look.
Motion: Animated road lines on the login screen, smooth transitions, and hover micro-interactions throughout.
UI Language: Card-based layouts, glowing borders, gradient accents, and a bold brand presence — built for an immersive user experience.

## FEATURES
AUTONEXUS offers a complete front-end experience centered around car exploration and analysis. The application opens with a secure authentication portal where users must enter valid credentials before accessing any content — invalid attempts trigger inline error messages and toast notifications, while successful logins redirect users to the main dashboard. An auth guard is implemented across all inner pages, automatically sending unauthenticated visitors back to the login screen.
Once logged in, users land on a home dashboard that serves as the central hub for navigating the platform. From there, they can explore personalized car suggestions curated based on preferences, or head to the analysis page for data-driven comparisons and insights between vehicles.
The interface is fully responsive, adapting cleanly to both desktop and mobile screen sizes. The login page features a subtle road animation — moving lines across the bottom of the screen — that reinforces the automotive theme. Throughout the app, smooth CSS transitions and hover effects give every interaction a polished, premium feel consistent with the overall dark gold aesthetic.

## TECHNOLOGIES USED
AUTONEXUS is built entirely using core web technologies without any frameworks or external libraries, keeping it lightweight and fast. The structure and content of every page is written in HTML5, using semantic elements for clarity and accessibility. All visual styling — including the dark theme, golden accent colors, CSS variables, animations, and responsive layout — is handled through CSS3. The interactive behavior of the application, including login validation, session management, page redirection, and toast notifications, is powered by vanilla JavaScript (ES6+). The distinctive typography comes from Google Fonts, specifically the Orbitron font for the brand logo and Exo 2 for body text, both loaded directly from the Google Fonts CDN. Authentication state between pages is maintained using the browser's built-in sessionStorage API, ensuring users stay logged in during their session without needing a backend. Node.js and npm are included for development tooling and package management.
